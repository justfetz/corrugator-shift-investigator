Narrative judge

Grade narratives

Judged narratives

The checks above score numbers and routing; nothing in them reads a model's prose. A DeepEval G-Eval judge scores each narrative a recorded run writes on five rubric lines, 0 or 1 each, never blended. It is a model call, so it runs only from the owner's machine (evals/run.py --judge), never in the CI gate and never from this page, and it is trusted only as far as it agrees with the owner's own grades of the same narratives.

Verified examples

The examples

Wordings read another way
Wordings asked in a stand-in window

Each verified example (src/investigator/examples.json) pairs one of the owner's SLT questions with the exact semantic query that answers it, checked against hand-written SQL. Its question in the owner's words and five rewordings are asked of the offline router on the golden page, and a wording reads correctly when the plan it gets is the example's. A wording asked in a window the semantic model does not read yet (read in its interim; none since PR #186 added the year to date) is asked in a stand-in window, another question: it is listed apart and never counted as a pass. The score is reported, never a gate: the read-back planner (issue #172) owns raising it.
