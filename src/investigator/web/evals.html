Judged narratives

The checks above score numbers and routing; nothing in them reads a model's prose. A DeepEval G-Eval judge scores each narrative a recorded run writes on five rubric lines, 0 or 1 each, never blended. It is a model call, so it runs only from the owner's machine (evals/run.py --judge), never in the CI gate and never from this page, and it is trusted only as far as it agrees with the owner's own grades of the same narratives.
