How to build this agent

1. Define the process

Interview a plant expert. Write down units, shift boundaries, grade targets and waste denominators before generating records. Paper changes equal wet-end runs.

2. Generate consistent records

Paired knives share lineal travel. Cuts, outs, widths and rejected sheets reconcile to area. A seeded generator gives repeatable scenarios, including deliberately invalid records.

3. Give the agent small tools

Python validates inputs; fixed, parameterized DuckDB queries calculate KPIs, setup intervals, rankings and notes. The model can request tools, never supply arbitrary SQL or chart values.

4. Run the bounded loop

Question + selected scope + recent context → tool selection → validation → calculation → evidence → next tool or finish. The offline planner teaches this flow without API charges.

5. Show the evidence

Charts and matrices use tool results. Open “How the agent got here” to inspect arguments, SQL, data coverage and timing. Notes are reported observations, not instructions or proven causes.

6. Test and control cost

Test known totals, interval overlaps, missing data, scope escapes and invented evidence. Live mode uses bounded calls and persistent spending reservations. PDF exports use the retained result; they do not ask the model again.
